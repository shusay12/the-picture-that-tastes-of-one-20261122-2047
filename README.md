A program that draws one delicious picture: a steaming bowl of ramen, seen from above — glossy golden broth, tangled wheat noodles, chashu pork, a soft egg with a molten yolk, green onion, nori and chopsticks on a warm wood table. Drawn procedurally, pixel by pixel, with the Python standard library only: no network, no downloaded photos, no third-party packages. Deterministic — two runs write byte-identical PNGs.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024 PNG, well under the 1 MiB gate).
